# V2 environment variable names

This file lists names only. Secret values must be held in a deployment secret manager and must not be pasted into logs, reports, or command history.

## Runtime and limits

`WELLAR_ENV`, `WELLAR_LOG_LEVEL`, `WELLAR_QUEUE_BACKEND`, `WELLAR_DB_PATH`, `WELLAR_QUEUE_CAPACITY`, `WELLAR_MAX_ATTEMPTS`, `WELLAR_LEASE_SECONDS`, `WELLAR_RETRY_BASE_SECONDS`, `WELLAR_MEDIA_BACKEND`, `WELLAR_MEDIA_ROOT`, `WELLAR_MEDIA_RETENTION_DAYS`, `WELLAR_LABEL_RETENTION_DAYS`, `WELLAR_RATE_LIMIT_PER_MINUTE`, `WELLAR_MAX_VIDEO_BYTES`, `WELLAR_MAX_IMAGE_BYTES`, `WELLAR_MAX_AUDIO_BYTES`, `WELLAR_MAX_VIDEO_SECONDS`, `WELLAR_MAX_AUDIO_SECONDS`, `WELLAR_MAX_VIDEO_FRAMES`, `WELLAR_MAX_IMAGE_PIXELS`, `WELLAR_MAX_MEDIA_TOTAL_BYTES`, `WELLAR_MAX_MEDIA_PER_TENANT_BYTES`, `WELLAR_MAX_CONCURRENT_UPLOADS`, `WELLAR_VIDEO_SAMPLE_HZ`.

## Identity and storage

`WELLAR_AUTH_MODE`, `WELLAR_DEV_AUTH_TOKENS_JSON`, `WELLAR_OIDC_ISSUER`, `WELLAR_OIDC_AUDIENCE`, `WELLAR_OIDC_JWKS_URI`, `WELLAR_OIDC_TENANT_CLAIM`, `WELLAR_OIDC_ALGORITHMS`, `WELLAR_DIRECTUS_URL`, `WELLAR_DIRECTUS_PULL_ENABLED`, `WELLAR_DIRECTUS_SERVICE_TOKEN`, `WELLAR_DIRECTUS_TIMEOUT_SECONDS`, `WELLAR_POSTGRES_DSN`, `WELLAR_POSTGRES_AUTO_MIGRATE`, `WELLAR_POSTGRES_POOL_MIN`, `WELLAR_POSTGRES_POOL_MAX`, `WELLAR_POSTGRES_POOL_TIMEOUT`, `WELLAR_POSTGRES_CONNECT_TIMEOUT`, `WELLAR_POSTGRES_STATEMENT_TIMEOUT_MS`, `WELLAR_S3_BUCKET`, `WELLAR_S3_REGION`, `WELLAR_S3_ENDPOINT_URL`.

Decoder/deadline settings include `WELLAR_DECODE_TIMEOUT_SECONDS`, `WELLAR_DECODE_MEMORY_LIMIT_MB`, and `WELLAR_WORKER_DRAIN_SECONDS`. Deployment smoke-check settings are `V2_VERIFY_BASE_URL`, `V2_VERIFY_BEARER_TOKEN`, `V2_VERIFY_ALLOW_STAGING`, and `V2_VERIFY_ALLOWED_HOST`; these are tool inputs, not application settings. `deployment/easypanel/.env.template` contains names only.

## Model and deployment template

`WELLAR_MODEL_INFERENCE_ENABLED`, `WELLAR_MODEL_ARTIFACT_DIR`, `WELLAR_RESEARCH_IMAGE_DROWSINESS_ENABLED`, `WELLAR_RESEARCH_IMAGE_DROWSINESS_ARTIFACT_DIR`, `WELLAR_API_CPU_LIMIT`, `WELLAR_API_MEMORY_LIMIT`, `WELLAR_WORKER_CPU_LIMIT`, `WELLAR_WORKER_MEMORY_LIMIT`.

Label storage fails closed unless `WELLAR_LABEL_RETENTION_DAYS` is a positive integer. The default rate limit is process-local; multi-replica enforcement requires a shared limiter.
